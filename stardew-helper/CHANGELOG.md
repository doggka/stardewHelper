## v5 (в работе) — переезд в десктопное приложение

- Electron + Vite + TypeScript, портативный exe без установки и прав администратора
- Node лежит портативно в `.toolchain`, в систему ничего не ставится
- трекер разложен из одного `index.html` по `data / logic / screens / ui`
- окно без системной рамки со своим заголовком
- **чтение сохранений**: приложение само находит `%AppData%\StardewValley\Saves`,
  показывает список ферм и подставляет прогресс и дату
- несовпавшие по составу узелки пропускаются поштучно, а не рубят весь импорт
- прогресс хранится отдельно по каждому сейву
- экран модов с описаниями, статусами из папки `Mods` и кликабельными ссылками
- `install-mods.ps1`: SMAPI и UI Info Suite с GitHub, остальное через папку `drop`

### Что проверено

Трекер до и после разбивки на модули: 31 узелок, 131 предмет, те же слоты
и порядок; «можно сейчас» по сезонам — 27 / 34 / 33 / 23 с теми же названиями;
поиск даёт те же вердикты.

Парсер сохранений на шести реальных сейвах. Собранное приложение проверено
через отладочный порт: `Podkabluk` импортировал 13 предметов и 1 закрытый узелок,
дата переключилась на лето, день 8; в «Комнатах» 27 карточек, 6 комнат,
13 отмеченных галочек.

## v4 — локация по сезонам

Баг: у предмета была одна локация на все сезоны, из-за чего шампиньон весной показывался
зелёным «можно сейчас», хотя весной он растёт только в тайном лесу, куда без стального
топора не попасть.

- добавлено поле `locS` — переопределение локации на конкретный сезон
- Шампиньон: весна — тайный лес, осень — везде
- Красный гриб: шахта круглый год вместо ложного замка тайного леса
- Твердая древесина: убран замок леса
- Морской ёж: летом весь пляж, в остальные сезоны — восточная часть за мостом
- Красная капуста: добавлено условие «нужны семена»
- Зимний корень: убран чип шахты
- тэги-фильтры перестали выглядеть отключёнными

## v3 — фильтры, база предметов, поиск с опечатками

## v2 — локации, умный поиск, торговка

- карта долины с маркером, карты зон, 23 локации
