# home-tools

Локальные самоделки-утилиты. Каждая штука живёт в своей папке, история общая.

| Проект | Что это | Как запустить |
|---|---|---|
| [stardew-bundle-tracker](stardew-bundle-tracker/) | Трекер узелков Общественного центра Stardew Valley с подсказками по сезонам/погоде/локациям и планом на 1-й год | открыть `stardew-bundle-tracker/index.html` в браузере |

## Соглашения

- Инструменты по возможности — один самодостаточный HTML-файл без сборки и без интернета.
- Состояние пользователя — `localStorage` + кнопки экспорта/импорта JSON.
- Репозиторий локальный, remote не настроен.
