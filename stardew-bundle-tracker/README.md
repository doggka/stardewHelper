# Трекер узелков Stardew Valley

Открыть `index.html` в браузере. Работает офлайн, прогресс в `localStorage`.
**Папку `img/` держать рядом с `index.html`** — там карта долины и карты локаций.

## Что умеет

- Все **30 узелков** Общественного центра (6 комнат) + Пропавший узелок ДжоджаМарта.
  Число слотов сверено с вики (Хозяйственный — 6 из 12, Отборный урожай — 3 из 4,
  Приключенца — 2 из 4, Краболовный — 5 из 10).
- Переключатели **сезона, дня (1–28) и погоды**. День даёт день недели — шапка сразу
  показывает, стоит ли сегодня торговка и через сколько дней следующий визит.
- Цвета статусов: 🟢 можно сейчас · 🟡 при условии · 🔵 позже в этом году ·
  🟠 последний сезон сбора · 🟣 вне сезона, только у торговки · 🔴 в Y1 уже никак.
- **📍 Кликабельные локации**: карта долины 400×244 с маркером (координаты взяты с вики),
  описание «как добраться», карта самой зоны и ссылка на статью.
- **🔒 Запертые локации видно сразу** — чип вида `🔒 Тайный лес · нужен стальной топор`
  стоит прямо у предмета, без клика.
- **Поиск-вердикт**: вводишь название предмета → нужен ли он для узелков, в каких,
  сколько штук, какое качество, обязательный или на выбор, отмечен ли уже, почём у торговки
  и ссылка на вики. Если не нужен — так и пишет.
- Вкладки: «Не продолбать», «Комнаты», «План по сезонам» (+ блок «Что открыть заранее»),
  «🛒 Торговка», «Доступно сейчас».
- Экспорт/импорт прогресса в JSON.

## Странствующая торговка

Отдельная вкладка: расписание (пт/вс 06:00–20:00 в Пепельносмольном лесу; каждый день
на Ночном рынке 15–17 зимы и Пустынном фестивале 15–17 весны), список покупок с реальными
диапазонами цен и суммой «сколько держать в кармане», галка «Гарантия завершения первого года».

**Чего она не продаёт никогда** — важно, потому что на эти предметы запасного плана нет:
Сено, Кварц, Аквамарин, Земляной кристалл, Замерзшая слеза, Огненный кварц, Морозная жеода,
Радужный осколок, Древний плод, Лосось пустоты, Динозавровый майонез.
И отдельно: товары у торговки **всегда обычного качества**, поэтому **Отборный урожай
(золотые ×5) купить невозможно** — только вырастить.

## Ключевые ловушки 1-го года (вшиты как предупреждения)

| Предмет | Проблема |
|---|---|
| Красная капуста | Семена у Пьера только с Y2. В Y1 — торговка (пт/вс) или дроп в Пещере Черепа. Посадить до ~19 лета. |
| Иглобрюх | Только лето + только ясно + 12:00–16:00. |
| Съедобный папоротник | Тайный лес, только лето. Нужен стальной топор. |
| Сморчок | Тайный лес, весна. Тоже упирается в стальной топор. |
| Яблоко ×3, Гранат | Саженцы у Пьера только осенью, растут 28 дней → сажать **в теплицу** или покупать у торговки. |
| Абрикос, вишня, апельсин, персик | Успеешь вырастить, только если купить саженец в первые дни сезона. Проще взять у торговки или пропустить — Хозяйственный узелок 6 из 12. |
| Раковина наутилуса | Пляж только зимой. |
| Песковник | Только пруд в пустыне → Сейф (42 500 з.) надо закрыть раньше Аквариума. |
| Жёлтый судак | Осень + только дождь, 12:00–2:00. |
| Трюфель / шерсть / кроличья лапка | Цепочка хлев → большой → элитный + животное. Копить с весны. |
| Отборный урожай | Золотое качество, у торговки не купить. Удобрение + прокачка фермерства. |
| Доска объявлений | Не закрывать до 1 весны Y2, иначе Кент не получит очки дружбы. |

## Данные

Источники: [Узелки](https://ru.stardewvalleywiki.com/%D0%A3%D0%B7%D0%B5%D0%BB%D0%BA%D0%B8) и
[Странствующая торговка](https://ru.stardewvalleywiki.com/%D0%A1%D1%82%D1%80%D0%B0%D0%BD%D1%81%D1%82%D0%B2%D1%83%D1%8E%D1%89%D0%B0%D1%8F_%D1%82%D0%BE%D1%80%D0%B3%D0%BE%D0%B2%D0%BA%D0%B0)
на ru.stardewvalleywiki.com. Картинки в `img/` — оттуда же.

Набор узелков — **стандартный**, не «смешанный» (remixed). Remixed включается галкой
в Advanced Options при создании фермы.

Правятся руками константы в начале `<script>`: `LOC` (локации), `CART` / `NEVER` (торговка),
`ROOMS` (узелки), `PLAN` / `GATES` (план по сезонам).
