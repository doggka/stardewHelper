# Трекер узелков Stardew Valley

Один самодостаточный HTML-файл. Открыть `index.html` в браузере — всё работает офлайн,
прогресс сохраняется в `localStorage`.

## Что умеет

- Все **30 узелков** Общественного центра (6 комнат) + Пропавший узелок ДжоджаМарта.
  Число слотов сверено с вики (например Хозяйственный — 6 из 12, Отборный урожай — 3 из 4,
  Приключенца — 2 из 4, Краболовный — 5 из 10).
- Для каждого предмета: **сезон, погода, время суток, локация, условие** (улучшенный топор,
  уровень шахты, элитный хлев, доступ в пустыню) и текст «где добывать» по клику на `?`.
- Переключатели **сезона и погоды** вверху — предметы перекрашиваются:
  🟢 можно сейчас · 🟡 при условии · 🔵 позже в этом году · 🟠 последний шанс в Y1 · 🔴 окно прошло.
- Вкладка **«Не продолбать»** — что закрывается в текущем сезоне, что уже упущено,
  и что требует долгой подготовки.
- Вкладка **«План по сезонам»** — ручной чеклист на Весну/Лето/Осень/Зиму 1-го года
  плюс автоматический расчёт, какие узелки реально закрыть к концу каждого сезона.
- Вкладка **«Доступно сейчас»** — плоский список под текущий сезон и погоду.
- Поиск по предметам, экспорт/импорт прогресса в JSON, сброс.

## Ключевые ловушки 1-го года (вшиты как предупреждения)

| Предмет | Проблема |
|---|---|
| Красная капуста | Семена у Пьера только с Y2. В Y1 — странствующая торговка (пт/вс) или дроп в Пещере Черепа. Посадить до ~19 лета. |
| Иглобрюх | Только лето + только ясно + 12:00–16:00. |
| Съедобный папоротник | Тайный лес, только лето. Нужен стальной топор. |
| Яблоко ×3, Гранат | Саженцы у Пьера только осенью, растут 28 дней → сажать **в теплицу**, иначе в Y1 не успеть. |
| Раковина наутилуса | Пляж только зимой. |
| Песковник | Только пруд в пустыне → Сейф (42 500 з.) надо закрыть раньше Аквариума. |
| Жёлтый судак | Осень + только дождь, 12:00–2:00. |
| Трюфель / шерсть / кроличья лапка | Цепочка хлев → большой → элитный + животное. Копить с весны. |
| Доска объявлений | Не закрывать до 1 весны Y2, иначе Кент не получит очки дружбы. |

## Данные

Источник: [ru.stardewvalleywiki.com/Узелки](https://ru.stardewvalleywiki.com/%D0%A3%D0%B7%D0%B5%D0%BB%D0%BA%D0%B8).
Набор узелков — **стандартный**, не «смешанный» (remixed). Remixed включается галкой
в Advanced Options при создании фермы; если её не трогали — набор стандартный.

Данные лежат в константе `ROOMS` в начале `<script>` — править руками просто.
