# Stardew Helper Bridge

SMAPI-мод на одну задачу: выгружает ассортимент странствующей торговки в файл,
чтобы его прочитало приложение Stardew Helper.

## Зачем

Снаружи этот список не узнать. Игра собирает его на лету из номера сейва
и номера дня, а в 1.6 ещё и новым генератором случайных чисел
(`useLegacyRandom: false`). Написать предсказатель можно, но ошибка в нём хуже
отсутствия: распланируешь день под товар, которого не будет.

Изнутри игры список просто лежит готовым объектом — мод его читает и пишет
в файл. Это факт, а не прогноз.

**Что важно, а что нет — решает приложение, не мод.** Мод отдаёт сырой список;
приложение знает состав узелков, что уже отмечено и свои предупреждения,
поэтому говорит не «что-то есть», а «семена красной капусты, 650 з. — бери
обязательно».

## Что пишет

`Mods/StardewHelperBridge/state.json`, при загрузке сейва, в начале дня
и при открытии любого магазина:

```json
{ "saveId": "452028593", "day": 11, "season": "spring", "year": 1,
  "weather": "sun", "cartPresent": true,
  "cart": [ { "name": "Семена красной капусты", "price": 650, "stock": 5 } ] }
```

Мод ничего не меняет в игре: только читает состояние и пишет свой файл.
Если что-то пойдёт не так, ошибка уходит в лог SMAPI и игра не падает.

## Сборка

```powershell
$env:Path = "C:\Users\doggm\projects\home-tools\.toolchain\dotnet;" + $env:Path
dotnet build -c Release
```

.NET SDK 6 лежит портативно в `../.toolchain/dotnet`, в систему не ставился.

Пакет `Pathoschild.Stardew.ModBuildConfig` сам находит игру, подтягивает ссылки
и **копирует готовый мод в `Mods` после каждой сборки**. Если это не нужно,
добавь в `.csproj`:

```xml
<EnableModDeploy>false</EnableModDeploy>
```

## Про API

Между 1.5 и 1.6 нужные методы переименовали. Правильные имена для 1.6
(проверены рефлексией по сборке игры, а не по памяти):

| Что | 1.6 |
|---|---|
| Повозка сегодня | `Forest.travelingMerchantDay` |
| Идентификатор магазина | `Game1.shop_travelingCart` = `"Traveler"` |
| Ассортимент | `StardewValley.Internal.ShopBuilder.GetShopStock(shopId)` |
| Цена и количество | `ItemStockInformation.Price`, `.Stock` |

Если после обновления игры мод перестанет собираться — скорее всего снова
переименовали. Утилита `../.toolchain/apiprobe` печатает реальные сигнатуры
из сборки игры.
